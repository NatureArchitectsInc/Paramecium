# README — Paramecium

## 概要

**Paramecium** は、FreeCAD の UI を通じてパラメトリックな形状を定義・編集できる、Grasshopper 向けプラグインです。
Grasshopper上の入力に加えて、FreeCADで幾何拘束や変数を視覚的に編集することで、柔軟かつ直感的に部品モデルを構築できます。

名前の由来：parametric に似た綴りの生物、ゾウリムシ（Paramecium）から。

---

## 使い方

1. コンポーネントをキャンバスに配置し、必要に応じて以下の入力を与えます：
   - **Base Geometry**（形状の元）
   - **Reference Geometry**（参照用形状）
   - **Variable Names / Values**（数式変数とその値）
   - **FCStd Path**（既存のFCStdファイルを使用する場合は入力。）
2. コンポーネントを **ダブルクリック**すると FreeCAD が起動し、部品モデルや拘束の内容をGUIで編集できます。
3. 編集内容は `.FCStd` ファイルに保存され、Grasshopper 側に反映されます。

- Grasshopper に返される形状は、ラベルに `return` を含むフィーチャーです（大文字小文字は区別しません）。該当がなければ最後のフィーチャーが返されます。
- FCStd Path を入力しない場合、FCStd は .gh ファイルに埋め込まれて保存されます。

### ファイルの扱い

- 計算の途中で使うファイル（STEP、変数の JSON、ログなど）は、`%TEMP%\Paramecium\` の下にある作業フォルダに作られ、計算が終わると削除されます。FCStd と同じフォルダには作られません。
- ダブルクリックで開いた FreeCAD では、作業用のコピーを編集します。保存して閉じると、その内容で元の FCStd が置き換えられます。保存せずに閉じた場合は、元の FCStd は変更されません。
- FCStd Path を指定している場合は、置き換える前に元の FCStd を同じフォルダへ `<名前>.<日時>.FCBak` として残します（例：`bracket.20260925-153000.FCBak`）。元に戻したいときは、拡張子を `.FCStd` に変えて開いてください。

### 変数（Variable Names / Values）の使い方

Grasshopper から渡した数値を、FreeCAD の寸法などに数式で結び付けられます。

1. **Grasshopper 側**：`VarNames` に変数名のリスト、`VarValues` に値のリストを、同じ順番・同じ個数で入力します。
   - 例：`VarNames` = `length`, `radius`、`VarValues` = `50`, `3`
   - 変数名に使えるのは英字・数字・`_` で、先頭は英字か `_` にしてください（`-` や空白は使えません）。
2. **FreeCAD 側**：変数は、ドキュメント内の `ghVarSet` というオブジェクトに、同じ名前のプロパティとして追加されます（Variables グループ）。コンポーネントを一度計算すると作られます。
3. コンポーネントをダブルクリックして FreeCAD を開き、Pad の長さやスケッチの拘束寸法などの入力欄で `=` を入力するか、入力欄の右にある青い丸のアイコンをクリックして数式エディターを開きます。
4. `ghVarSet.length` のように「`ghVarSet.` + 変数名」で参照します。`ghVarSet.length * 2` や `ghVarSet.radius + 1 mm` のような式も書けます。
5. 保存して FreeCAD を閉じると、以降は Grasshopper で値を変えるたびに、その値で再計算された形状が返されます。

- 名前は大文字と小文字を区別します（`ghvarset.length` では参照できません）。
- 値は単位のない数値として渡され、長さとして使うと FreeCAD の既定の単位（mm）で解釈されます。
- Grasshopper 側で入力から外した変数も、`ghVarSet` には最後の値のまま残ります。

### エラー・警告の表示

- 通常の再計算（ダブルクリックしない場合）は FCStd を上書きしません。FreeCAD 側で失敗しているフィーチャーがあると、コンポーネントに赤いエラーが表示されます。
- ダブルクリックで編集した場合は、FreeCAD を閉じた時点の最終的なモデルの状態で判定します。編集の途中で出たエラーは表示せず、コンポーネントの **Log** 出力にだけ残します。

## FreeCAD・Python環境の設定

- FreeCADのインストールが必要です。https://www.freecad.org/downloads.php?lang=ja
- **FreeCAD 1.1 以降を推奨します**（1.0 でも動作します）。
- Python環境はFreeCADに同梱のものを使用します。
- 使用する FreeCAD バージョンやパスが異なる場合、`setting.json` で設定してください。
- `setting.json` は `.gha` と同じフォルダにあります。python.exe が見つからない場合は、コンポーネントに `setting.json` の場所を示すエラーが表示されます。


### `setting.json` の例

```json
{
  "python_path": "C:\\Program Files\\FreeCAD 1.1\\bin\\python.exe"
}
```

### FreeCAD のバージョンが異なるファイルについて

FCStd を保存した FreeCAD と、`setting.json` で指定した FreeCAD のバージョン（1.0、1.1 など）が異なる場合、次のように動作します。

- **通常の再計算**：コンポーネントにオレンジの警告を表示します。ファイルは上書きしません。
- **ダブルクリック**：編集を始める前に、続けるかどうかを確認するダイアログを表示します。
  - 「はい」を選んで保存すると、実行中の FreeCAD の形式でファイルが上書きされます。
  - 「はい」を選んで保存せずに閉じた場合は、ファイルが古いバージョンのままなので、警告を表示し続けます。
  - 「いいえ」を選ぶと編集せず、既存のファイルのまま形状だけを返します。

FreeCAD 1.1 で追加された機能（新しいデータムや原点の点など）を使ったファイルを 1.0 で扱うと、その部分への参照がエラーなしに失われることがあります。複数のバージョンを混ぜて使う場合は注意してください。

## トラブルシューティング

- **FreeCAD の画面の一部（数式エディターの補完候補など）が黒く表示される**
  古い FreeCAD の設定が残っていることが原因の場合があります。`%APPDATA%\FreeCAD` フォルダの名前を変えて（例：`FreeCAD~`）、設定を初期化してください。
- **旧版（FreecadGH）からの移行**
  Grasshopper の Libraries フォルダに `FreecadGH.gha` が残っていると、Paramecium と競合します。削除してください。既存の .gh ファイルはそのまま開けます。
